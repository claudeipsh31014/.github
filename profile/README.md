<p>把家宽 IP 接到 Claude 上，配置本身并不复杂，麻烦的是参数分散在三个地方：路由器、代理服务端、浏览器。任何一处填错，症状都长得差不多——打不开、能打开但提示异常、用一会儿掉线。这篇按参数清单的方式来写，先把六组关键参数的作用和取值摆清楚，再分别说路由器、鉴权、浏览器三处怎么填，最后给五条命令做验收，照着核对一遍基本能定位到具体哪一格写错了。</p>

<h2>二、路由器侧：WAN 接法、LAN 网段与端口转发</h2>
<p>家用宽带线路进来之后，第一步是让它能上网，第二步才是让内网设备走这条出口。两步之间有依赖关系，顺序不能反。</p>
<h3>WAN 口三种接法怎么选</h3>
<p>供应商给的是静态地址时，WAN 设静态 IP，把地址、掩码、网关、DNS 四项照抄，DNS 建议先填供应商给的，通了再换公共 DNS 做对比。给的是账号密码时用 PPPoE，注意服务名留空。只有一条网线、地址由上游分配时用 DHCP，但要确认地址不会每天变，否则等于没有固定出口。</p>
<h3>LAN 网段别和上游撞车</h3>
<p>常见错误是把路由器 LAN 设成 192.168.1.1，而上游光猫也是这个网段，结果内网设备分不清往哪走，表现为时通时不通。改成 192.168.50.1 这类不常见网段，DHCP 池留出足够地址，改完重启一次再测。</p>
<h3>端口转发的边界</h3>
<p>只有需要从外网访问内网设备时才做端口转发，日常让内网走代理不需要。若确实要做，只转发必要的单个端口，不要图省事开 DMZ——DMZ 会把整台设备暴露在外网，风险与便利不成比例。</p>

<h2>三、代理鉴权：三种方式对号入座</h2>
<p>鉴权决定"谁能用这条出口"。三种方式各有适用面，选错了要么天天掉线，要么把凭据泄漏出去。</p>
<h3>账号密码：最通用，也最容易外泄</h3>
<p>配置最简单，浏览器和绝大多数客户端都支持。缺点是凭据存在本地配置文件里，多人共用一台机器时等于共享账号。建议一个账号一套凭据，离职或换人时立即在后台重置，不要沿用旧密码。</p>
<h3>IP 白名单：省事，但把出口绑死</h3>
<p>把办公网或服务器的公网地址加进白名单，之后不用再填密码。代价是换网络就得改白名单，家庭宽带动态地址尤其麻烦。适合固定办公场地，不适合经常出差或移动办公。</p>
<h3>隧道与证书：机器对机器才用得上</h3>
<p>需要长期跑脚本时，可以走加密隧道或双向证书，把鉴权做在链路层。配置门槛高一些，但凭据不以明文形式出现在请求里，适合有一定运维能力的团队。</p>

<h2>四、浏览器侧：代理开关之外的四个设置</h2>
<p>代理通了不等于环境一致。浏览器还有几项设置会影响服务端对这次访问的判断，容易被忽略。</p>
<h3>系统代理与浏览器独立配置</h3>
<p>系统代理省事，所有程序一起走，但会连累本地的更新和同步服务。浏览器插件或独立配置更干净，只为指定窗口生效，缺点是忘记开就会直连。团队协作时建议统一用独立配置，并把"先看插件是否开启"写进日常检查。</p>
<h3>时区、语言与 WebRTC</h3>
<p>出口在美国西岸而系统时区是东八区、语言是简体中文，这类组合本身很常见，但若账号资料填的是美国地区，矛盾就明显了。WebRTC 可能绕过代理暴露本机地址，浏览器设置里关掉或限制为仅代理解析，能减少一类不必要的暴露。</p>

<h2>五、五条命令验收出口是否按预期生效</h2>
<p>配置完不要只看网页能不能打开，用命令逐项确认更可靠。Windows 用 PowerShell，macOS 和 Linux 用终端，命令基本一致。</p>
<h3>从链路到出口逐层确认</h3>
<p>先 ping 网关确认线路通，再 curl ipinfo.io 看出口地址和 ASN，然后 curl ifconfig.me 交叉验证，接着测一次目标站点的响应时间，最后连续跑十分钟看地址是否漂移。五步都过，配置才算完成；任意一步异常，回到对应章节改参数，不要一次性改动多项。</p>

<h2>常见问答</h2>
<h3>路由器配置好了，电脑还是直连怎么办？</h3>
<p>答：先确认电脑连的是这台路由器的 LAN 口或它的 Wi-Fi，而不是光猫的 Wi-Fi。再看电脑有没有装过其他代理软件接管了系统代理，把它退出后重测。</p>
<h3>代理能通但速度很慢，是参数错了吗？</h3>
<p>答：多数情况不是参数问题，而是线路带宽或晚高峰拥塞。先用 speedtest 测本地带宽排除自家网络，再在不同时段各测三次对比，若只有晚八点到十一点慢，属于线路容量问题。</p>
<h3>白名单和账号密码可以同时开吗？</h3>
<p>答：可以，两者是并列关系，满足其一即可通过。实际配置里同时开启能减少单点失效，但排查时要记得两条路径都存在，否则会误判为鉴权没生效。</p>
<h3>换了路由器需要重新配置吗？</h3>
<p>答：需要把 WAN 参数、LAN 网段、代理设置重新填一遍，代理后台的鉴权信息不用改。建议换之前把旧路由的配置页截图存档，照着填能少踩坑。</p>

<h2>合规提示</h2>
<p>以上配置用于自有账号的正常网络访问，请勿用于违反服务条款或规避地区限制的用途。采购前确认供应商具备相应资质，保留开通单和计费记录，便于后续对账。</p>
<p>路由器与代理凭据属于敏感信息，建议定期更换并限制知悉范围。文中价格与参数取值为常见示例，实际以供应商开通单为准。</p>
